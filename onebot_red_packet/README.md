# QQ 抢红包插件

该插件仅对项目内置 QQ 生效。内置协议桥负责识别钱包消息和调用 QQ 原生领取接口，Python 插件负责策略、延迟、去重和统计。

安装后自动领取默认开启。后台侧边栏的“QQ 抢红包”页面可配置领取类型、随机延迟、群/用户/关键词黑白名单、停止时段、口令红包、感谢回复、通知目标和主人 QQ，并可查看统计与历史记录。

配置主人 QQ 后，可使用以下命令控制当前登录账号：

- 红包开启
- 红包关闭
- 红包状态

同时完整兼容原 NapCat 版的 `#抢红包` / `#红包` 管理指令，包括仅通知、延迟、防检测、黑白名单、过滤模式、停止时段、感谢消息、主人 QQ 和统计重置。

首次部署或更新协议桥后需要重启对应的内置 QQ 账号。运行配置保存在本目录的 data/state.json；通过后台保存后即时生效。

外接 OneBot 实现需要自行兼容 notice.elaina_red_packet 事件和 elaina_grab_red_packet 动作，否则本插件不会尝试领取。

本插件仅作为仓库内手动插件维护，不加入 `ElainaCore/Elaina-plugins` 的 `onebot_plugins.json`，因此不会出现在框架插件市场。
