# 官机代发拦截插件

从 napcat-plugin-amsghook 迁移到 ElainaBot-Onebot1 的大型插件。插件拦截框架插件发起的 OneBot 消息发送，按来源插件执行文本替换、追加后缀，并可改由 QQ 官方机器人发送。

## 依赖与安装

- 需要支持 api_interceptor 和 handler_filter 的 ElainaBot-Onebot1 版本。
- 自动群映射和回调唤醒需要框架内置 QQ；外接 OneBot 可使用文本变换，但通常无法提供内置键盘回调数据。
- 将整个 onebot_amsghook 目录安装到框架 plugins 目录，在后台侧边栏打开“官机代发”配置。

框架只提供通用的出站 API 中间件、处理器过滤器和内置 QQ 协议能力。本插件的配置、官机网关、拦截规则和映射均保留在插件目录内。

## 配置

在管理页填写 QQ 开放平台机器人的 AppID、Secret 和官机 QQ。规则名称必须等于框架插件目录名；无法识别来源的直接 OneBot 调用使用“OneBot 外部调用”。

- 启用规则：应用该来源的文本替换和后缀。
- 官机代发：该来源的群消息改由官方机器人发送。
- 全局官机代发：所有支持的群消息都尝试由官方机器人发送。
- 替换规则：格式为 原文=新文;原文2=新文2。
- 仅主人、屏蔽群和屏蔽用户：可全局设置，也可对每个目标插件单独设置。

官机必须已加入目标 QQ 群。群第一次触发代发时，插件会让内置 QQ @ 官机并建立群号、群 OpenID 和回调按钮映射；失败或超时会回退原始 OneBot 发送。

图片、视频和语音均可代发。语音会使用插件 bin 目录中的 silk_codec 转码；系统需要可执行的 ffmpeg，或 Python 环境已安装 imageio-ffmpeg。转码条件不满足时会自动回退原始 OneBot 发送。

主人可在群内发送 dm 内容直接走官机代发，发送“官机状态”查看连接状态。运行配置和群映射分别写入 data/config.json、data/mappings.json。
