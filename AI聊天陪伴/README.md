# AI 聊天陪伴

ElainaBot v2 聊天陪伴插件，提供猫娘、温柔伙伴、傲娇少女、理性助手等内置人格。

## 功能

- OpenAI Chat Completions 兼容协议
- 直接使用中央 AI 模块中的接口、密钥与模型清单
- 插件内可选择自动策略、指定接口或指定接口与模型
- 群聊按群共享上下文，私聊按用户隔离上下文
- 全量群聊消息记录、按群回复概率与冷却，防止机器人刷屏
- SQLite 持久化上下文，AI 可参考群聊记录自然参与对话
- 可选公网搜索与网页读取工具，内置 SSRF 防护、网页域名白名单并隐藏所有 IP
- 可配置违规词，输入拦截、输出替换，违规原文不会进入上下文
- Web 面板管理模型偏好、人格、触发方式及上下文
- 群聊默认需要 @ 机器人，可在面板开启自动回复

## 命令

- `/ai`：查看状态与人格列表
- `/ai clear`：清空当前会话上下文
- `/ai personality <ID>`：主人切换全局人格

先安装并启用 `v2模块/ai_llm` 中的 AI LLM 服务模块，在该模块统一配置接口、API Key、模型优先级与故障切换。插件首次加载后，在侧边栏进入「AI 陪伴」选择自动策略或指定接口/模型，并配置人格即可使用。
