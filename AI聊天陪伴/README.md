# AI 聊天陪伴

ElainaBot v2 聊天陪伴插件，提供猫娘、温柔伙伴、傲娇少女、理性助手等内置人格。

## 功能

- OpenAI Chat Completions 兼容协议
- 直接使用中央 AI 模块中的接口、密钥与模型清单
- 插件内可选择自动策略、指定接口或指定接口与模型
- 每个用户使用独立上下文，私聊、艾特和全量群消息模式均不会共享群上下文
- 支持识别用户消息中的一张或多张图片（最多 8 张）；QQ 临时图片会先下载为内联数据，再以 OpenAI 多模态输入传给当前聊天模型，纯图片消息也可以直接触发对话
- 可在面板独立开启私聊流式消息，使用 QQ 私聊流式接口发送已审核答复
- 全量群聊消息记录；未艾特消息先判断相关性，再应用概率、冷却和每小时预算
- SQLite 持久化用户独立上下文，不混入其他群成员的消息
- 支持最多 128k Token 上下文；达到预算时自动将完整历史压缩为摘要，不再按 500 条消息硬截断
- 人格可按会话覆盖；支持用户显式保存、查看和清除长期记忆
- 支持按人格配置人物集：可填写人物身份、性格、人物经历、补充设定和人物之间的关系，每个人格独立选择当前人物集并注入对话背景
- 内容安全在用户输入和 AI 待发送回复两个阶段独立审核；审核过程不进入上下文，也不向用户展示
- 可选公网搜索与网页读取工具，内置 SSRF 防护、网页域名白名单并隐藏所有 IP
- 模型工具列表、定义和执行均从中央 AI LLM 获取；可在陪伴面板逐项启用，聊天不会展示工具名称、参数与执行过程
- 支持可命名的陪伴资源；每项可配置用途说明、正文、公开 URL，或上传本地图片、语音和视频，由模型按需读取或直接发送
- 一个内容安全总开关统一控制输入审核、输出审核和附加违规词；分类请求只返回安全或违规标记，审核请求与违规原文不会进入聊天上下文
- AI 陪伴内置头像 meme 合成，按语境临时提供工具，不依赖娱乐拓展的 meme 实现
- 独立生图旁路，可配置多个接口/模型的优先顺序并在失败时自动切换
- TTS 角色语音默认关闭；不填 token 每天 100 字，填 token 可获得更高转换额度（以服务端权益为准），超额或报错静默跳过。启用后在合适的情境主动使用：问候与早安晚安、安慰陪伴、感谢庆祝、亲近/挚友之间的闲聊（均受冷却限制）；`/ai voice on` 可开启个人语音偏好，日常闲聊优先发语音；群聊仅在用户明确要求时发送，查资料等信息型回答始终用文字
- 可配置违规词，输入拦截、输出替换，违规原文不会进入上下文
- Web 面板管理聊天模型、生图旁路、人格、人物集、Skills、触发方式及上下文
- 群聊默认需要 @ 机器人，可在面板开启自动回复

## 拟人智能（学习与主动交互）

面板新增「拟人智能」页，能力设计参考 AstrBot 官方市场插件（self_learning、proactive_chat、favourpro、livingmemory 等）：

- **反思链路**：每 N 轮成功对话后异步触发一次低成本「反思调用」，一次产出风格候选、好感度变化、心情与自动记忆候选；可在面板单独配置辅助接口与模型（默认跟随聊天模型），并设置触发间隔
- **对话风格学习**：优先从用户明确喜欢或纠正过的表达中提取模式，并保留用户原话，攒够阈值后由 AI 归并为可复用的风格规则；支持人工审核、启停与删除，审核通过后注入系统提示
- **群黑话理解**：全量群消息按群统计高频词，过阈值后由 AI 结合上下文判断是否为黑话并解释含义；仅对开启全量消息的群生效，词条可审核
- **好感度与情绪**：按用户维护 0–100 好感度、关系阶段（陌生/认识/熟悉/亲近/挚友）、当前心情与用户画像，注入影响语气亲疏；可手动修正或重置
- **自动长期记忆**：依据用户原话提取事实与偏好，保存证据、来源会话与变更记录；用户明确纠正时可更新旧自动记忆。手动记忆独立保留，自动记忆达到上限或过期时不挤掉手动记忆；`/ai memories` 展示真实 ID、来源与依据
- **主动消息**（默认关闭）：闲置搭话承接旧话题、时段问候；支持免打扰时段、每日配额、最小间隔与最小好感度门槛，群聊仅对 `appid:group_id` 白名单生效，发送前过内容审核，失败静默记录

## 命令

- `/ai`：查看状态、人格列表、好感度心情与学习概况
- `/ai clear`：清空当前用户的独立上下文
- `/ai personality <ID>`：主人切换当前会话人格
- `/ai remember <内容>`：保存个人长期记忆
- `/ai memories`：查看个人长期记忆
- `/ai forget [ID]`：按真实 ID 删除一条或清空个人长期记忆
- `/ai correct <ID> <内容>`：纠正个人记忆，纠正后作为手动记忆保护
- `/ai styles`：查看当前人格对你生效的风格 ID
- `/ai feedback <风格ID> <原因>`：停止对你使用该风格，不影响其他用户
- `/ai voice [on|off]`：查看或设置个人语音偏好

先从模块市场安装并启用 `ai_llm` 服务模块，在该模块统一配置接口、API Key 和模型目录。聊天模型和生图旁路均只能从中央目录选择；生图旁路按后台列表从上到下尝试 `/images/generations`，失败后继续切换模型或接口。头像 meme 和 base64 生图结果需要 `image_hosting` 的 COS 图床。

图片识别需选择支持视觉输入的模型；支持 Chat Completions、Responses 及更新后的 `ai_llm` Gemini 原生适配。支持 QQ 附件中的 PNG、JPEG、GIF 和 WebP（实际支持格式仍以模型为准），单张最多 10MB、本轮合计最多 15MB。仅处理当前消息及复合消息内可下载的图片附件，不从文字链接猜测图片，也不读取缺少下载地址的 Ark 图片或历史引用图片。图片只用于当前轮，后续追问需要时请重新发图；内容安全输入预审仍仅检查文字。

## 插件工具与学习维护

AI LLM 是独立的模型服务，通过 `complete()`、`stream_complete()`、`run_agent()` 和原生工具注册提供能力，工具按发起请求的插件隔离；人格、记忆、会话和主动消息由陪伴插件维护。聊天陪伴在每次请求中提供自己已启用的时间、人物集、语音、生图、联网和资源工具；可以在中央 AI LLM 服务下载或用 AI 创建公用 Agent 工具，再在陪伴面板中选择启用；陪伴自己的内置工具不向中央公用列表上报。

- 风格归并失败或返回空规则时保留候选；按人格分别归并，避免不同人格混用；面板候选「通过」后直接生成生效规则。
- 风格审核、停用、删除和个人负反馈在下一轮读取时生效。关闭反思只暂停学习，已批准内容仍可使用；单项功能开关仍控制注入。
- 群黑话在后台按周期处理，不阻塞聊天；真实消息频次累加，普通词判定会保留，避免反复消耗模型调用。
- 用户纠正或删除记忆会作废旧后台反思，防止已忘记的事实重新写回。
- 主动私聊只选择曾与机器人私聊过的用户，不把仅在群聊出现的用户作为私聊目标。发送前重新检查免打扰和活跃状态；成功发送的文本写入聊天历史，便于接续话题。

## 离线回归验证

在插件仓库根目录运行：

```text
python -m unittest discover -s AI聊天陪伴/tests -v
node AI聊天陪伴/tests/test_panel.cjs
```

测试使用临时 SQLite 数据库与模拟模型，不连接真实机器人平台，不读取生产聊天记录。
