# 群管中心 3.0.2

以现有 groupguard 的群管理能力为基线，合入「群管中心 v2.0.0」中的通用欢迎与审核功能。无需新增依赖，继续使用框架的插件页面、登录鉴权、群资料与消息发送接口。

## 面板与功能

- 工作概览：管理统计、群管状态与最近操作。
- 监管规则：保留禁言、解禁、踢人、违禁词、链接/卡片/转发过滤、刷屏处罚、发言撤回及普通入群审批。
- 入群验证：算术验证、管理员跳过、失败处罚；新增验证期间禁言秒数和达到失败次数后的禁言秒数。默认分别为 0（沿用等待时间）和 600 秒，保持旧行为。
- 入群欢迎：群级文案与原生消息按钮、0–240 秒延迟、合并欢迎、每日发送上限、机器人级监控开关和群列表模式。
- 不活跃群唤醒：使用框架成员活跃索引提取群列表；列表中的群有新成员通过验证后发送唤醒文案，成功后移出列表，失败保留。
- 配置审核：群管理员使用 `设置欢迎语 文案` 提交，面板通过或驳回。提交不会改动生效文案；通过前再次检查群级与全局违禁词。
- 内容词库、消息模板和管理记录：沿用原有功能，统一更新视觉与布局。
- 消息模板实时预览：与框架共用 Markdown 渲染器及消息样式，提供聊天气泡、Markdown／纯文本切换、原生按钮、可编辑示例变量、图片放大、代码复制。编辑表单与完整 JSON 草稿均可预览；预览不会保存模板或发送 QQ 消息。

欢迎任务与算术验证共用单一入群事件入口：启用验证的群在验证通过后才排队欢迎。无验证的群直接进入欢迎流程。重复入群通知去重，退群取消待发送欢迎，卸载取消所有延迟任务。欢迎配置和群列表按机器人与群隔离。

## 删除与排除范围

已删除小程序权限绑定命令、开发者连接页面、远端凭据读写与测试接口、远端同步任务以及 remote_access 存储代码。新装不再创建远端权限表；已有数据库中的历史表和配置文件不会自动删除，插件不再读取它们。

没有移入 Roblox 绑定、Astudlox 集成、Roblox 规则与专属入群审批链、外部用户后台/OAuth/互联映射，也没有导入脱敏包中的运行状态、密钥或业务数据。当前提供本地词库检查和机器人主人在面板进行的配置审核。

## 升级与数据

将本目录作为 `groupguard` 插件更新，然后通过框架重新加载插件。页面 key 和 API 前缀继续为 `groupguard`、`/api/ext/groupguard`。

原有 `data/group_manager.db` 和 `data/reply_templates.json` 沿用，已有群管配置和模板保持原值。新欢迎表在加载时幂等创建于同一数据库。欢迎默认按群关闭，需在「入群欢迎」中为目标群开启。没有自动搬迁其他插件目录的数据；若部署中另有欢迎插件，应先关闭该插件的通用欢迎入口，以免双发，定制功能应保留独立。

新增群内指令：

- 群管理员：`开启欢迎`、`关闭欢迎`、`设置欢迎语 文案`。
- 机器人主人：`开启群成员入群监控`、`关闭群成员入群监控`、`提取群列表`、`测试发送模板`、`测试发送合并模板`。

欢迎支持变量：`{user_id}`、`{user_ids}`、`{username}`、`{group_id}`、`{count}`。按钮格式与原群管消息模板一致。

## 本地验证

在插件仓库根目录运行，框架仓库默认位于同级 `ElainaBot_v2`：

```powershell
python groupguard/tests/test_merge.py -v
node --check groupguard/assets/panel.js
node --test groupguard/tests/test_template_preview.mjs
python -m compileall -q groupguard
```

隔离预览：`python groupguard/tests/preview.py`，访问 `http://127.0.0.1:8768`。预览使用临时样例数据库，七个页面使用实际面板 API；`/mobile` 提供 390px 预览，`/?theme=dark` 检查深色主题。预览不启动机器人，不连接 QQ；退出后临时数据清理。

真实 QQ 入群事件、主动消息权限和发送结果仍需在部署环境验收。

消息预览部署时直接使用已打包的本地资源，无 CDN 或新增 Python 依赖。框架渲染器更新后，开发环境可运行 `node groupguard/tools/build-preview.mjs`，默认从同级 `ElainaBot_v2_web` 的源码和已安装依赖更新；也可将前端仓库路径作为第一个参数。生成文件带源文件 SHA-256，第三方许可位于 `assets/PREVIEW_LICENSES.txt`。
